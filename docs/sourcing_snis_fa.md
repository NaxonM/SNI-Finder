# یافتن و جمع‌آوری دامنه‌های معتبر کلودفلر (SNI) برای دور زدن فیلترینگ

برای پیدا کردن بهترین نام‌های دامنه (SNI) که با موفقیت از سیستم‌های فیلترینگ و بازرسی پکت‌ها (DPI) عبور می‌کنند، به یک لیست باکیفیت از دامنه‌های کاندیدا که پشت شبکه کلودفلر میزبانی می‌شوند نیاز دارید.

پایدارترین و مقاوم‌ترین SNIها، **سایت‌های بسیار پربازدید و معروف** هستند؛ چرا که اپراتورها و ارائه‌دهندگان اینترنت (ISPs) به دلیل ترس از ایجاد خرابی‌های جانبی گسترده (قطع شدن دسترسی به خدمات عمومی بزرگ)، تمایلی به فیلتر کردن کامل آی‌پی‌ها یا رنج‌های آن‌ها ندارند.

این راهنما موثرترین روش‌ها برای یافتن و جمع‌آوری هزاران دامنه کلودفلر جهت اسکن در ابزار SNI-Finder را توضیح می‌دهد.

---

## 🛠️ روش اول: استفاده از ابزار خودکار فیلتر لیست Tranco (پیشنهادی)

برای ساده‌تر کردن فرآیند جمع‌آوری دامنه‌های پربازدید، یک اسکریپت پردازش موازی و بهینه‌سازی شده در پروژه قرار داده‌ایم: **`scripts/extract_cf_from_tranco.py`**.

این اسکریپت رتبه‌بندی جهانی دامنه‌ها را از فایل CSV دانلودی پروژه Tranco خوانده، دامنه‌ها را به صورت همزمان Resolve می‌کند، آی‌پی آن‌ها را با رنج‌های رسمی کلودفلر تطبیق می‌دهد و دامنه‌های جدید را مستقیماً به انتهای فایل `config/sni-list.txt` شما اضافه می‌کند!

### روش استفاده:
۱. **دانلود لیست ۱ میلیون سایت برتر Tranco** از وب‌سایت رسمی [Tranco List Project](https://tranco-list.eu/).
۲. فایل CSV دانلودی را به پوشه پروژه منتقل کرده و نام آن را به `tranco_334VL.csv` تغییر دهید (یا نام فایل را در اسکریپت ویرایش کنید).
۳. اسکریپت کمکی را با تعیین تعداد دامنه‌های برتر برای بررسی (مثلاً ۵۰۰۰ دامنه‌ اول) اجرا کنید:
   ```bash
   # در ویندوز
   python scripts/extract_cf_from_tranco.py 5000
   
   # در لینوکس (با فعال بودن محیط مجازی)
   python3 scripts/extract_cf_from_tranco.py 5000
   ```
۴. اسکریپت به طور خودکار دامنه‌ها را بررسی کرده، موارد تکراری را حذف کرده و تمام دامنه‌های فعال پشت کلودفلر را به انتهای `config/sni-list.txt` پیوست می‌کند!

## 👥 روش دوم: لیست‌های گیت‌هاب که توسط انجمن‌ها نگهداری می‌شوند

توسعه‌دهندگان و کاربران فعال حوزه دور زدن فیلترینگ، لیست‌های به‌روزی از دامنه‌های فعال پشت کلودفلر را منتشر می‌کنند:
* **[v2fly/domain-list-community](https://github.com/v2fly/domain-list-community)**: معتبرترین دیتابیس متن‌باز که قوانین مسیریابی پروکسی‌های V2Ray/Xray را تغذیه می‌کند.
  - پوشه [data](https://github.com/v2fly/domain-list-community/tree/master/data) را بررسی کنید. فایل‌هایی مانند `category-ads-all`، `geolocation-!cn` یا `google` حاوی هزاران دامنه فعال پشت CDNها هستند.
* **لیست دامنه‌های فعال IRCF**: در گیت‌هاب مخازنی مانند `ircfspace/active-domains` یا `MortezaBashirgange/CleanIP-SNI` را جستجو کنید که فایل‌های متنی خام برای اسکن دامنه‌ها را به اشتراک می‌گذارند.

## 🌐 روش سوم: ابزارهای جستجوی معکوس آی‌پی (Reverse IP)

اگر یک آی‌پی کلودفلر را در اختیار دارید، می‌توانید با جستجوی معکوس، تمام دامنه‌هایی که از آن آی‌پی استفاده می‌کنند را پیدا کنید:
۱. یک آی‌پی کلودفلر را از `config/cf_subnets.txt` انتخاب کنید (مثلاً `104.16.12.250` یا `104.19.230.21`).
۲. به یکی از سایت‌های زیر مراجعه کنید:
   - **[ViewDNS.info (Reverse IP Lookup)](https://viewdns.info/)**
   - **[HackerTarget (Reverse IP)](https://hackertarget.com/reverse-ip-lookup/)**
۳. آی‌پی را وارد کنید تا لیست بزرگی از وب‌سایت‌های فعال کلودفلر که روی این آی‌پی میزبانی می‌شوند را دریافت کنید.

## 🗺️ روش چهارم: استفاده از سرویس‌های ثبت DNS (SecurityTrails / DNSdumpster)

می‌توانید دامنه‌هایی که از سرورهای نام (Nameserver) رسمی کلودفلر استفاده می‌کنند را استخراج کنید:
* **[SecurityTrails](https://securitytrails.com/)**: یک اکانت رایگان بسازید، سرورهای نام کلودفلر (مانند `*.ns.cloudflare.com`) را جستجو کنید تا میلیون‌ها دامنه را مشاهده کنید.
* **[DNSdumpster](https://dnsdumpster.com/)**: نام یک شرکت بزرگ میزبانی‌شده روی کلودفلر (مثل `hcaptcha.com` یا `letsenrypt.org`) را جستجو کنید تا تمامی زیردامنه‌های (Subdomains) آن را استخراج کنید. زیردامنه‌ها کاندیداهای فوق‌العاده‌ای برای اسکن هستند زیرا ترافیک حساسی ندارند اما همان ویژگی‌های عبور پکت کلودفلر را دارا می‌باشند.
